## Highlights

### Mobile app (Flutter)

- **Multi-protocol** — WireGuard, IKEv2, OpenVPN, and StrongSwan in one app.
- **One-tap connect** with an animated world map, live download/upload speed and session stats.
- **Light & dark themes** with a clean, modern, recently redesigned UI.
- **Smart server list** — latency indicators, search, and gated premium locations.
- **Anonymous by design** — device-based access, no sign-up or login friction.
- **Built-in localization** — multiple languages delivered from the server and cached offline (English ships in the app).

### Monetization (freemium)

- **In-app purchases / subscriptions** for Google Play and the App Store.
- **AdMob** banner, interstitial, rewarded, and app-open ads — with a single **master on/off switch**.
- **Premium tier** unlocks premium servers and removes ads.
- Every **ad unit ID and ad cap is managed remotely** from the admin — no app rebuild needed.

### Security

- **End-to-end AES-256-GCM encryption** of server configs — decrypted only on the device, at connect time.
- **HMAC-signed requests** to prevent tampering, with **key-rotation** support.
- Secrets are never shipped in plaintext and never returned by the API.

### Admin panel (Nuxt PWA)

- **Role-based access control** with roles and granular permissions.
- **Server & country management** with encrypted configs.
- **Localization editor** for keys and per-language translations.
- **Remote app config** — AdMob, ad caps, feature flags, minimum version / force-update.
- **CMS pages** (privacy, terms, about) plus a dashboard and monitoring.
- Installable **PWA**, responsive light UI.

### Backend (Node.js + Sequelize)

- **Express API** on **MySQL / MariaDB**, with migrations and a flexible, selectable seeder.
- **Guided setup wizard** (`npm run db:initialize`) for a zero-guesswork first run.
- **Store receipt validation** (Google & Apple) ready to wire.
- **Firebase** Analytics, Crashlytics, and Performance on the mobile side.
